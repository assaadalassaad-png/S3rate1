# مشروع s3rate — تحويل صفحة HTML إلى APK

## أين أضع الكود؟
افتح الملف **`index.html`** الموجود في المجلد الرئيسي للمشروع، واحذف محتواه التجريبي، ثم الصق كود صفحتك الكامل مكانه واحفظ الملف.

إذا كان مشروعك يستخدم ملفات CSS أو JavaScript أو صوراً منفصلة، ارفع هذه الملفات أيضاً إلى GitHub مع الحفاظ على مساراتها، وقد تحتاج إلى تعديل إعداد النسخ في سير العمل إذا كانت ملفاتك موزعة على مجلدات.

## رفع المشروع إلى GitHub
1. أنشئ مستودعاً جديداً على GitHub باسم `s3rate`.
2. ارفع جميع ملفات ومجلدات هذا الملف المضغوط إلى المستودع، وليس ملف ZIP نفسه.
3. تأكد أن ملف `index.html` وملف `package.json` ومجلد `.github` موجودة في المستوى الرئيسي للمستودع.
4. افتح تبويب **Actions** في المستودع.
5. اختر **Build s3rate APK** ثم اضغط **Run workflow**، أو انتظر حتى يبدأ البناء بعد رفع الملفات.
6. بعد نجاح العملية، افتح نتيجة التشغيل وانزل إلى **Artifacts**.
7. نزّل `s3rate-apk` وفك ضغطه؛ ستجد داخله `app-debug.apk`.
8. انقل ملف APK إلى هاتف Android وثبّته. قد يطلب الهاتف السماح بالتثبيت من مصدر الملفات الذي استخدمته.

## ملاحظات
- هذا القالب يبني APK تجريبياً قابلاً للتثبيت (Debug APK)، وليس نسخة متجر Google Play.
- لا ترفع ملف ZIP نفسه إلى المستودع؛ فك ضغطه وارفع محتوياته.
- إذا كان كودك يعتمد على ملفات خارجية، ارفعها أيضاً مع الحفاظ على أسماء المجلدات والمسارات.
- إذا فشل البناء، افتح سجل التشغيل في GitHub Actions وأرسل رسالة الخطأ للمساعدة في إصلاحها.
